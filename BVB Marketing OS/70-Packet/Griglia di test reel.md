# Griglia di test reel

## A cosa serve
Pianificare un ciclo di 6 reel in 2 settimane in cui ogni reel cambia una sola variabile rispetto a un controllo; da compilare con il Regista prima della produzione.

## Contenuto
Variabili ammesse e valori:

| Variabile | Controllo | Varianti |
|---|---|---|
| Hook | domanda | numero della clinica / scena di clinica / errore comune |
| Formato | Massimo in camera | faceless Buzzy sullo stesso script / testo su B-roll |
| Durata | 30 s | 15 s / 45 s |
| Apertura | parlato | testo in sovrimpressione nei primi 3 s + parlato |
| CTA | "salva" | "commenta [parola]" / "link in bio al lead magnet" |
| Orario | 12:45 | 7:45 / 19:15 |

Griglia da compilare (una riga per reel):

| # | Settimana | Tema (da comment-mining) | Variabile | Controllo | Variante | Data e orario | Record Airtable | Risultato (×controllo su saved / retention 3 s) | Vince? |

| 2 | W43 | | Hook | | | | | | |
| 3 | W43 | | Formato | | | | | | |
| 4 | W44 | | Formato | | | | | | |

Criterio di vittoria: variante ≥ +30% sul controllo su salvataggi o retention al secondo 3. Due vittorie consecutive della stessa combinazione → template.
